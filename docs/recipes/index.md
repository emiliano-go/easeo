# Recipes { #recipes }

Ready-to-use patterns for real-world scenarios. Each recipe shows the inputs
and the resulting payload shape.

| Recipe | Schema | Key features |
|--------|--------|--------------|
| [Blog Post](blog-post.md) | Article | Image dimensions, breadcrumbs, author, registry |
| [Product Page](product-page.md) | Product | SKU, price, availability, breadcrumbs |
| [Category Page](category-page.md) | CollectionPage | Title templates, default OG image |
| [Search Results](search-results.md) | SearchResultsPage | `noindex,follow`, allowed query params |
| [Multi Language](multi-language.md) | Article | `locale`, `locale:alternate`, overrides |
| [Custom JSON-LD](custom-schema.md) | any | SchemaRegistry + hooks |
